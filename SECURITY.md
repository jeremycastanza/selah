# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Selah, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email: **jcastanza.me@gmail.com**

Include:
- A description of the vulnerability
- Steps to reproduce
- Any relevant logs or screenshots

## Response Timeline

- **Acknowledgment:** Within 48 hours
- **Assessment:** Within 7 days
- **Fix or mitigation:** As soon as practical, depending on severity

## Scope

This policy applies to the `selah` binary and its source code. The bundled KJV Bible data (`data/kjv.sqlite`) is public domain content and not in scope for security reports.

Thank you for helping keep Selah safe.
